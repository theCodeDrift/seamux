Drive Cursor's `agent` CLI from the board, as well as Claude Code and Codex: dispatch Cursor chats, read and reply to them, approve or deny their commands (or pick Run Everything, so the rest of the chat's run unasked), stop, rename, close and resume them. Cursor cards carry Cursor's near-black corner, cream in dark mode. cmux has no wrapper for Cursor, so run `cmux hooks cursor install` once; until then Cursor stays greyed out in the dispatch bar.
